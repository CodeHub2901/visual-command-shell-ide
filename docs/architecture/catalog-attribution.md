# Catalog attribution

The core command descriptions and metadata are maintained by this project.
Selected community examples are adapted from
[tldr-pages](https://github.com/tldr-pages/tldr), whose page content is licensed
under [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Every bundled TLDR supplement records and exposes:

- the original page URL;
- the exact 40-character source revision;
- the retrieval date;
- the copyright notice; and
- the license name and URL.

The current snapshot is revision
`5ca248e494fba9776274f74362440708849e411f`, retrieved on 2026-07-18. It includes
adapted examples from the `ls`, `find`, `ps`, `free`, `lsblk`, and `git` pages.
The Java loader rejects missing or altered attribution fields and page URLs that
do not match the recorded revision and command ID. The renderer displays
attribution as inert text so untrusted documentation cannot initiate navigation.
