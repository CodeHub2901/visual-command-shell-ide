# ADR 0002: Framed JSON-RPC over standard input/output

- Status: Accepted
- Date: 2026-07-18

## Decision

Use JSON-RPC 2.0 envelopes inside `Content-Length: N\r\n\r\n` frames. Length is the UTF-8 byte count. Frames are limited to 16 MiB initially. Requests use string IDs generated by Electron. Public methods are major-version namespaced (`v1.*`).

Worker stdout is protocol-only. Diagnostics go to stderr or rotating files. A malformed frame terminates the worker connection rather than attempting an unsafe stream resynchronization.

## Consequences

Payloads may safely contain newlines and terminal text. Partial/multiple frames, Unicode byte length, oversized payloads, corrupt headers, timeouts, cancellation, and worker termination need explicit tests.
